# War State v0.4

This archive contains the current source tree for the War State Roblox project.

Open `default.project.json` with Rojo 7.7.0. Static map files are already generated under `src/Workspace/Map`.

Run `python -m unittest discover -s tests -t . -v` before making further changes.

The archive is intentionally source-first: a real Rojo 7.7.0 build should be produced before treating the place file as a release build.
